# 교훈 (반복 금지 목록)

trade-analyst는 모든 분석 전에 이 파일을 읽는다. 항목은 삭제하지 않고 누적한다.

형식:
```
## L-번호: 한 줄 요약
- 날짜:
- 무슨 일이 있었나:
- 원인:
- 재발 방지 규칙:
```

## L-001: 수수료 미반영 성과 보고 금지 (초기 규칙)
- 날짜: 2026-10-21
- 무슨 일이 있었나: 사전 등록 규칙
- 원인: 업비트 KRW 왕복 수수료 0.1%는 단타 전략의 우위를 통째로 상쇄할 수 있음
- 재발 방지 규칙: 모든 성과 수치는 수수료와 슬리피지를 차감한 순수치로만 보고한다
